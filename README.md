# BD ESPORTS MS 🏆

**BD ESPORTS MS** is a modern, responsive Free Fire Esports Tournament and Diamond Top-Up Web Platform. Designed with a mobile-first user interface for gamers, tournament organizers, and community managers.

---

## ✨ Features

- **🎮 Esports Tournaments**:
  - Solo, Duo, and Squad Match Lobbies
  - Match schedule, entry fee, prize pool, and survival points setup
  - Instant Room Code & Password delivery for joined players
  - Live Leaderboards and Match Results

- **💎 Diamond Top-Up Store**:
  - In-Game UID Top-Up (Weekly, Monthly, Level Up Pass, Diamonds)
  - Instant order submission with user UID and payment transaction ID

- **💳 Wallet & Payment Integration**:
  - bKash and Nagad Deposit & Withdrawal support
  - Real-time balance update and transaction logs
  - Pending/Approved status tracking

- **🔔 Notification System**:
  - In-app notification center for room codes, deposit updates, and results

- **⚙️ Admin Control Panel**:
  - Manage matches, publish room details, approve deposits/withdrawals, and update tournament results

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Motion
- **Build Tool**: Vite

## 🚀 Getting Started

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mdmobarokk308-stack/bd-esports-app.git
   ```

2. Navigate into the directory:
   ```bash
   cd bd-esports-app
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run development server:
   ```bash
   npm run dev
   ```
